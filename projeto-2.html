Presença Digital: Psicologia

Um resumo rápido do que é este projeto

A landing page foi desenvolvida utilizando WordPress e Elementor, permitindo criar uma interface personalizada, moderna e alinhada à identidade profissional da psicóloga. Durante o desenvolvimento, trabalhei na organização das seções, hierarquia visual, tipografia e disposição dos elementos para proporcionar uma navegação simples e intuitiva.

Um dos principais pontos do projeto foi pensar na responsividade desde o desenvolvimento, adaptando a estrutura para diferentes tamanhos de tela e garantindo uma boa experiência principalmente em dispositivos móveis. Dessa forma, conteúdos, imagens, botões e espaçamentos foram ajustados para manter a página funcional, agradável e acessível tanto em desktop quanto em smartphones e tablets.
